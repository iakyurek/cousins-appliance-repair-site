Before Your Visit

What this usually means

A little preparation before your appliance repair visit can make the appointment smoother and help the technician get started faster. Start by clearing the area around the appliance so there is enough space to inspect it safely.

It also helps to think through what the appliance is doing. Note when the issue started, whether it happens every time, and if there are any unusual sounds, smells, leaks, or error codes. This information can help narrow down the possible cause.

If you know the appliance brand or model number, feel free to have it ready. The model number can be useful if parts need to be checked or ordered.

If the appliance has leaked water, produced smoke, sparked, or created a burning smell, stop using it until it has been inspected. Safety comes first, and a technician can help determine the next step.
